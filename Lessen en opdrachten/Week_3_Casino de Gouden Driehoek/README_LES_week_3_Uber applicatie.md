# Uber applicatie | 3
## Doel
Je maakt een applicatie waarin gebruikers van een gebruik kunnen maken van hun Uber 
dienst via de commandline. 
## Gegevens
De gebruikers kunnen kiezen uit 3 verschillende diensten met elk een eigen prijs. Zorg dat 
deze diensten op een logische manier in je applicatie staan opgeslagen. 
De diensten zijn:
## ienst Prijs
Uber 
Black
2.00
Uber Van 3.50
Uber X 1.50
# Opdracht
Zorg dat de applicatie de volgende flow heeft: 
- De gebruiker kan kiezen uit 1 van de drie diensten
- De gebruiker kan aangeven hoeveel kilometer gereden moet worden
- De applicatie berekend de totale kosten
- De gebruiker krijgt te zien hoeveel de rit gaat kosten

De applicatie is volledig opgebouwd uit functies. De enige code die direct wordt 
uitgevoerd is het aanroepen van de ‘main’ functie.
Maak minimaal 3 functies, maar meer is beter.
